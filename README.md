# Materiały kursów

Strona: <https://razitpl.github.io/MachineLearningCourse/>

## Co tu jest

**Azure Machine Learning (DP-100)** - tłumaczenie na polski i dostosowanie materiałów
laboratoryjnych firmy Microsoft do kursu *DP-100: Designing and Implementing a Data Science
Solution on Azure*. Oryginalne ćwiczenia powstały dla wcześniejszej wersji usługi i zestawu
SDK w wersji 1; te zostały przepisane na **Azure Machine Learning SDK v2** i sprawdzone
na działającym obszarze roboczym. Dostępne w dwóch wersjach językowych: polskiej i angielskiej.

**Ćwiczenia z uczenia maszynowego** - zadania wprowadzające do samego uczenia maszynowego,
niezależne od Azure: praca z danymi, regresja, klasyfikacja, metryki, przeuczenie,
przygotowanie cech. Uruchamiane lokalnie w JupyterLab.

## Uwagi

Zawartość tego repozytorium jest **generowana** ze źródeł kursu. Ręczne zmiany zostaną
nadpisane przy kolejnym uruchomieniu generatora.

Materiały Microsoftu, na których oparta jest część dotycząca Azure, są udostępnione na
licencji MIT.
