# Projektowanie i wdrażanie rozwiązań analitycznych w Azure

## Ćwiczenia do kursu

Witaj w ćwiczeniach praktycznych do kursu DP-100 *Designing and Implementing an Azure Data Science Solution*. Ćwiczenia towarzyszą zajęciom i pozwalają przećwiczyć technologie omawiane na wykładzie.

Wykonuj je **po kolei**, uważnie trzymając się instrukcji w kolejnych plikach. Część ćwiczeń wymaga sklonowania tego repozytorium do własnego środowiska pracy.

> **Czego potrzebujesz**: ćwiczenia wymagają subskrypcji Microsoft Azure. Jeśli prowadzący jej nie udostępnił, możesz założyć bezpłatną wersję próbną na https://azure.microsoft.com.
